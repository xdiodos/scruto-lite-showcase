# FAQ

## Is Scruto Lite open source?

No. This repository is a public showcase repository. It does not include source code or scanner implementation.

## Can I use this repository to deploy Scruto Lite?

No. This repository does not include deployment files, backend code, scanner logic, or infrastructure configuration.

## What is included in this repository?

This repository includes public documentation, screenshots, sample reports, roadmap, and usage disclaimers.

## Is Scruto Lite a penetration testing tool?

Scruto Lite is designed for lightweight security awareness and basic website exposure review. It is not a replacement for a full penetration test or formal security audit.

## Can I scan any website?

No. Users are responsible for ensuring they have proper authorization before assessing any website, domain, or system.
