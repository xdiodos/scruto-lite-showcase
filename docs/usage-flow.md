# Usage Flow

Scruto Lite provides a guided assessment and reporting flow.

## Standard Flow

1. User visits the Scruto Lite landing page.
2. User reviews the security assessment notice.
3. User confirms the consent page.
4. User enters the target website or domain.
5. Scruto Lite validates the scan policy.
6. The assessment is processed.
7. A web report is generated.
8. User may download a PDF report.
9. User may provide feedback through the feedback channel.

## Key Pages

- Landing Page
- Consent Page
- Scan Page
- Web Report
- PDF Report
- Feedback Channel

## Notes

Users are responsible for ensuring that they have authorization before assessing any website, domain, or system.
