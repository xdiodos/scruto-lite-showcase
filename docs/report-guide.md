# Report Guide

Scruto Lite provides both Web Report and PDF Report output.

Reports may include:

- Assessment summary
- Overall grade badge
- Category scores
- Key findings
- Recommendations
- N/A indicators
- Footer disclaimer
- Feedback channel

## Grade Badge

The grade badge is designed as a communication aid. It should not be interpreted as a formal certification, compliance approval, or penetration testing result.

## Recommendations

Recommendations are aggregated and sorted to help users focus on practical improvements first.

## PDF Report

The PDF report is designed for sharing, review, and lightweight documentation purposes.
