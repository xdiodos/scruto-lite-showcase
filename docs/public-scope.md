# Public Repository Scope

This repository is a public showcase repository for Scruto Lite.

## Included

- Product introduction
- Usage flow
- Screenshots
- Sample reports
- Public documentation
- Roadmap
- Usage disclaimer

## Not Included

- Source code
- Backend implementation
- Scanner implementation
- Deployment scripts
- Infrastructure diagrams
- Internal security controls
- Full scan policy logic
- Abuse prevention implementation
- Private operational notes
- API secrets or credentials

This repository is not an open-source scanner repository.
