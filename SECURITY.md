# Security Policy

## Repository Scope

This repository is a public showcase repository for Scruto Lite.

It does not contain source code, scanner engine logic, backend implementation, deployment scripts, API secrets, internal infrastructure details, or operational security controls.

## Reporting Security Issues

If you believe you have found a security issue related to Scruto Lite, xDiodos, or this repository, please contact:

support@xdiodos.com

Please include:

- A clear description of the issue
- Steps to reproduce, if applicable
- Screenshots or report references, if available
- Your contact information

## Responsible Disclosure

Please do not publicly disclose potential security issues before xDiodos / OSSIP Lab has had a reasonable opportunity to review and respond.

## Unauthorized Testing

Do not perform unauthorized scanning, exploitation, denial-of-service testing, brute-force testing, or intrusive testing against xDiodos systems, Scruto Lite services, or any third-party systems.
